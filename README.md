# rdk-halif-aidl-L4-Vendor

This module brings all L4 Polaris AIDL VTS required Tests.

## Test Documentation

For comprehensive test coverage details, see [L4 Test Cases](docs/pages//L4_Testcases.md).

## Build Steps

This test suite is part of Unified VTS for AIDL HALs. For initial setup, environment configuration, and build instructions, please refer to the Unified VTS README documentation.

- **[Unified VTS README](https://github.com/rdkcentral/rdk-halif-aidl-unified-vts/blob/main/README.md)**

## Running the L4 Tests

While the Unified VTS can run all tests at once, you can execute the `VTS_L4_AVMODULE` test suite individually for targeted validation.
